# Basic Resistive Circuit

## Objective

Learn how to:
- Draw a circuit in LTspice
- Run a simulation
- Measure current through a resistor

## Circuit Parameters

- V1 = 20 V
- R1 = 1.5 Ω
- R2 = 14 Ω
- R3 = 2 Ω
- R4 = 2.5 Ω
- R5 = 4 Ω

## Simulation Setup

Analysis type:
.tran 60

## Result

I(R4) ≈ -2.27A

## What I learn?

- How to use LTspice
- How to connect components correctly
- How to run a simulation
